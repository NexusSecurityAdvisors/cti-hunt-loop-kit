# M3: Preflight and Data Reality Check (30 minutes)

**Goal:** a pass or fail preflight result for each hypothesis card, before any hunting.

## Tasks

1. (5 min) Open `lab/data/data_inventory.csv`. The PIRs ask about the last 30 days, so the hunt window is 2027-02-01 to 2027-03-03.
2. (15 min) Work through `templates/preflight-checklist.md` for Hypothesis A and Hypothesis B. For each data source the card needs, check the earliest available record against the window start.
3. (5 min) Fill in "data available" on both cards.
4. (5 min) Decide: which hypothesis can produce a bounded non-observation if nothing is found, and which can only be inconclusive? Write your answer on the card **before** you hunt.

## Discussion question

If a hunt fails preflight, should you still run it? (Yes, usually: it can still find something. But a clean result cannot be reported as a negative.)
