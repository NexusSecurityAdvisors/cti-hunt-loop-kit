# Security policy

This repository contains defensive hunting content and synthetic data only.

- **Found a problem with a query or rule** (false negatives, bypasses, bad logic)? Open an issue with the *Query bug* template. Bypass techniques that are already public are fine to discuss openly.
- **Found sensitive data committed by mistake** (real hostnames, credentials, customer data, TLP:AMBER+ material)? Do **not** open a public issue. Report it privately at https://github.com/NexusSecurityAdvisors/cti-hunt-loop-kit/security/advisories/new (the *Report a vulnerability* button on the Security tab).

Please do not submit real IOCs, telemetry or customer data in issues or pull requests. All contributions must be TLP:CLEAR.

## What to expect

- Acknowledgement within 3 business days.
- Sensitive material is removed from the repository, and from its history where needed, as soon as it's confirmed.
- Fixes to queries and rules ship in the next release, credited in the changelog unless you'd rather stay anonymous.
