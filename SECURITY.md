# Security policy

This repository contains defensive hunting content and synthetic data only.

- **Found a problem with a query or rule** (false negatives, bypasses, bad logic)? Open an issue with the *Query bug* template. Bypass techniques that are already public are fine to discuss openly.
- **Found sensitive data committed by mistake** (real hostnames, credentials, customer data, TLP:AMBER+ material)? Do **not** open a public issue. Report it privately through GitHub's *Report a vulnerability* button on the Security tab of this repository.

Please do not submit real IOCs, telemetry or customer data in issues or pull requests. All contributions must be TLP:CLEAR.
