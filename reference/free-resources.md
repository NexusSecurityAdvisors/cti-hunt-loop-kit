# Free Resources

| Resource | Use it for |
| --- | --- |
| [MITRE ATT&CK](https://attack.mitre.org) | Technique IDs for hypothesis cards |
| [ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/) | Coverage layers for detection metrics |
| [Summiting the Pyramid](https://center-for-threat-informed-defense.github.io/summiting-the-pyramid) | Scoring how durable a detection is |
| [PEAK threat hunting framework](https://www.splunk.com/en_us/blog/security/peak-threat-hunting-framework.html) | Hunt types and phases |
| [TaHiTI methodology](https://www.betaalvereniging.nl/wp-content/uploads/2026/03/TaHiTI-Threat-Hunting-Methodology-whitepaper.pdf) | Hunt process with CTI as an input |
| [ThreatHunting Project, Sqrrl archive](https://threathunting.net/sqrrl-archive) | Hunting Maturity Model and the hunting loop |
| [CTI-CMM](https://cti-cmm.org) | Mapping CTI services to security functions |
| [Psychology of Intelligence Analysis](https://www.cia.gov/resources/csi/static/Pyschology-of-Intelligence-Analysis.pdf) | Cognitive bias and analytic method |
| [ICD 203](https://www.dni.gov/files/documents/ICD/ICD-203.pdf) | Likelihood and confidence language |
| [NIST CSF 2.0](https://doi.org/10.6028/NIST.CSWP.29) | ID.RA-02 and ID.RA-03 evidence |
| [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | Prioritizing vulnerability hunts |
| [abuse.ch](https://abuse.ch) | ThreatFox, URLhaus, MalwareBazaar indicators |
| [Malcolm](https://www.cisa.gov/resources-tools/services/malcolm) | OT and network traffic analysis |
| [MISP](https://www.misp-project.org) | Intelligence sharing and storage |
| [OpenCTI](https://github.com/OpenCTI-Platform/opencti) | Intelligence platform with ATT&CK mapping |
| [Sigma](https://github.com/SigmaHQ/sigma) | Portable detection rules |
| [Velociraptor](https://docs.velociraptor.app) | Endpoint hunting at scale |
| [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) | Validating detections |
| [OWASP AI Exchange](https://owaspai.org) | Threats to AI-assisted CTI pipelines |
| [FIRST Traffic Light Protocol](https://www.first.org/tlp/) | Marking what can be shared |
